# TXT与EPUB转换工具

这是一个用于TXT和EPUB格式互相转换的本地网页应用。

## 功能特点

- 支持TXT转EPUB
- 支持EPUB转TXT（存在bug暂时不支持）
- 可自定义EPUB的字体大小、行间距和页边距
- 纯前端实现，无需后端服务器
- 简洁美观的用户界面

## 安装步骤

1. 安装依赖：
```bash
npm install
```

2. 启动开发服务器：
```bash
npm run serve
```

3. 访问应用：
打开浏览器访问 http://localhost:8080

![](img/1.png)

## 使用说明

1. 点击"选择文件"按钮，选择要转换的TXT或EPUB文件
2. 如果是TXT转EPUB，可以设置以下参数：
   - 字体大小（12-24）
   - 行间距（1-2）
   - 页边距（10-50）
3. 点击"开始转换"按钮
4. 转换完成后，文件会自动下载到您的下载文件夹
